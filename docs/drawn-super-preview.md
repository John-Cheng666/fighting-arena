# 杰米 SA3／CA 二维关键镜头样片

入口：`/drawn-super-preview.html`。招式演练选择 SA3／CA 后也有对应的预览链接。Vite 开发服务器及正式构建均包含此入口。

这是选择方案 D 后制作的第一轮关键镜头审阅材料，尚未替换正式战斗画面。两段各有 24 张新重绘关键帧，按 10 张／秒播放，在 60 Hz 审阅时钟上每张保持六帧。每段动作节选为 2.4 秒。SA3 总长 174 帧／2.9 秒，CA 总长 196 帧／约 3.27 秒，末尾保持最后一张画面，让既有原声自然收束。当前固定攻击方实际四酒、受击方零酒；没有宣称覆盖所有角色组合、酒级或完整招式。

SA3 选取命中后的连续打击、蓄势和双脚终结；CA 单独选取抓喉近景、拉近释放及终结连打。两段不是同一动画换色。

## 素材与方法

使用内置 **imagegen** 生成两套二维画面。完整提示词、输入角色参考与姿势参考的截取参数保存在 [`PROMPTS.json`](../public/assets/jamie/drawn-supers-v1/PROMPTS.json)。原始生成 PNG 与播放使用的 WebP 均保存在 `public/assets/jamie/drawn-supers-v1/`，原始生成文件也保留在工具默认目录。转换为 WebP 只做格式压缩，不改变或补画内容。

姿势参考来自工作区已有的 `cinematic/review-v3.mp4`：它是已有浏览器 3D 预览的录像，其身体动作与相机来自先前恢复的游戏资产，**不是原游戏实录**。以该录像每秒十次采样，排列为四列六行，分别在 4.65 秒与 12.85 秒截取 2.4 秒，再让 imagegen 按每格姿势重新绘制。人物身份与服装参考为官方 `official-jamie.png` 和项目已有的 `sprites-v3/f-supers.png`；官方 `reference/603.mp4` 用来核对演出风格。

两套播放图集大小约 1 MB 合计，只由 Canvas2D 播放；播放端不加载 3D 模型。每格裁切独立取整并留少量内边距，避免非整除尺寸导致相邻画面串入。直接切换完整画面，不用身体拉伸或两张人物交叉淡化来伪造补间。

PNG、WebP、源录像的尺寸与 SHA-256 汇总于 `manifest.json`。该文件用于来源审阅，不将 AI 重绘描述成原版动作帧。

## 时钟与原声

`src/drawn-super-preview/timeline.ts` 将局部时钟映射到各自动作的捕获时钟：SA3 从 279 帧起，CA 从 318 帧起。接触光和小幅震动只使用 `native-numerics.json` 中该区间的实际伤害接触；SA3 的零伤害释放不会制造闪光。使用的图片已含绘制的打击光，叠加光量很低。系统要求减少动态效果时关闭新增震动与闪光。

原声复用工作区已有的 `CinematicAudio`、`audio-timeline` 和经批准的音效／日语语音，按各自原动作帧定位。点击播放后才解锁并准备声音。暂停、回拖、切换、循环和变速会清理旧声音；后台标签自动暂停。1× 用于音画同步审阅；慢放继承既有播放器“音效缩放、语音保持自然音高”的行为。停格段属于样片音频收尾，不是新增原作动作。

支持播放／暂停、重播、60 Hz 逐帧、0.25／0.5／1×、循环、声音开关、全屏。键盘空格播放，左右键逐帧，M 切换声音；输入框和按钮保留各自键盘行为。

可用 `?move=CA&frame=48` 指定初始动作与局部帧，`?embed=1` 隐藏说明以便查看画面，`?silent=1&autoplay=1` 提供静音自动播放。

## 交付与验证

`review.mp4` 为实际二维画布和同一原声总线的连续录像，依次播放两段。`poster.jpg` 为二维 CA 画布截图。生成提示词不参与运行时加载。

```powershell
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vitest/vitest.mjs run
node node_modules/vite/bin/vite.js build
node scripts/verify-drawn-supers.mjs
```

时钟测试核对两段的原始接触帧、不同收尾、回拖确定性、关键帧边界和收声停格。实际浏览器检查播放、原声解锁、暂停清理、切换重置、逐帧、慢放、结尾、循环、移动端布局和减少动态效果。

## 审阅边界

这是 24 张／段的关键镜头样片，运动密度为十张／秒，并非原作的完整逐帧动画。生成画面仍存在脸部、手部、衣纹与头发的细小连续性差异；单格原始画幅约 340×190，放大后较软。要进入完整动画制作，还需逐镜补帧、提高单帧分辨率、修正接触与人物一致性，再制作启动、防御、落空、释放回战斗和 KO 分支。当前不改战斗判定、伤害或胜负时序。
