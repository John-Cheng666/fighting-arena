# 普通投的释放、推开和新角色接入

所有角色的普通投使用 `src/engine/systems/throws.ts` 的公共结算。当前释放后双方中心间距为前投170、后投240竞技场单位；后投完成一次换位。该距离是用户指定规则下的二维竞技场适配，不是《街霸6》的原始世界坐标。

## 捕获与释放契约

角色确认普通投时，在被投者的 `capture` 中保存普通投类型与当次动作锁定的方向：

```ts
target.capture = {
  sourceId: source.id,
  moveId: variant.moveId,
  untilTick: releaseTick,
  phase: "combo",
  normalThrow: {
    direction: "forward", // 后投为 "back"
    axis: { x: action.directionX, y: action.directionY },
  },
};
```

在清除捕获之前调用公共函数：

```ts
import { releaseNormalThrow } from "../../engine/systems/throws";

releaseNormalThrow(source, target, "complete");
target.capture = undefined;
```

按新角色文件所在目录调整导入路径。成功完成传`complete`，拆投传`tech`，被打断或其他取消传`interrupted`。杰米现有释放接口用`knockdown=true/false`区分完成和取消，因此拆投的取消分支也会消耗元数据，但不应用位移。

公共函数会核对捕获所属投手，消费本次普通投元数据，保证同一次释放只结算一次。拆投和中断不推开、不换位。指令投、SA和其他捕获不填写`normalThrow`，继续使用各自的释放行为；不能根据`throw: true`、角色ID或招式名称猜测普通投。

方向必须在本次出招/确认时锁定，不可在后投换位后从双方位置重算。后投换位由公共函数负责，角色模块不能再交换一次坐标。杰米原先在原生捕获释放和旧式最终击中的两处后投交换已移除。

## 场地边缘

公共结算同时约束双方坐标。投向归一化后计算间距向量，前投以投手位置为锚，后投以换位后投手位置为锚；如果一方会超出边界，就联合平移双方，保留投后距离。只限制受投者的位置会在贴墙时把间距压回近身。

沿斜向或竖直投掷时使用同一规则；只有目标间距超过该方向可用的场地跨度时才缩短。释放时清零双方残余速度，避免墙反弹和捕获前的移动把双方拉回。普通的身体碰撞分离仍由`separateFighters`处理。

## 杰米起身抢断问题

旧逻辑在前投释放后仍保持捕获姿势的53单位间距。现有宿主在确认后第73帧释放、第118帧结束固定倒地适配，而喝酒在第130帧发生；因此对方起身直接轻拳可以在喝酒之前命中。

本次补齐投后距离，保留实际命中、中断、受身与酒级规则。前投后相距170，后投相距240。回归测试在最早合法起身时调用正常出招API，让轻拳通过真实碰撞结算：两席位的投手都能完成一酒；把间距恢复成旧53单位则能再次观察到起身轻拳打断。饮酒仍会被实际命中的攻击中断。

## 原版资源核对

本轮使用REA打开并检查本机`StreetFighter6.exe`，身份SHA-256为`26095ad815bca8c58205814348315f132e74a74650c63fe1b2801c752643627c`。身份清单证据为`ev_4a159c7f466baf95c89b37d71fc3ebe05da0990a83e2d451ac0e8f3893d3800b`；该证据只用于可执行文件身份，不作为游戏运行行为证明。

随后按已保留目录项从原始PAK重新提取`021.fchar.18`、`000.fchar.18`、`attackdatacommon.fcmndatals.1`，重新核对压缩数据和解压SHA-256、动作CRC和27个确切字段的字节偏移。总共读取207,927字节目录项及压缩数据，未启动原游戏。`021.fchar.18`的SHA-256为`2e530707b0dceb86921937bcd72e3f6f89d828c7bf310f2da289e0c3bc0a354f`。

原始BranchKey在捕获局部`[80,81)`转到动作728；728的饮酒事件在局部50，可操作结束`MarginFrame=56`。原始锁定释放键使用零起点，表中释放帧沿用宿主的`from+1`映射。

`DestX`的155/151不等于双方最终中心间距；完整位移还涉及动作根位移、朝向与三维坐标。`Time`和`DownTime`也不能直接相加冒充完整受身时序。本次未把这些值直接用于二维距离，未改动现有45帧倒地适配；完整原版受身时钟仍需后续动态取证。

可复用的本地审计脚本、原始提取、REA证据和字段核对记录位于忽略目录`research/normal-throws/`，普通构建不依赖这些文件。

## 新角色检查

新增角色必须为普通前投、后投保存上述元数据，并在成功释放和取消路径调用公共函数。至少验证：前后投与换位、双席位和反向投向、贴墙及斜向、重复清理、拆投/空投/中断、PC，以及指令投和SA未套用普通投间距。核心回归使用两个非杰米测试角色，确保通用结算无需读取杰米状态。

运行`npm.cmd test -- src/engine/__tests__/throws.test.ts src/characters/jamie/__tests__/throws.test.ts`。整套战斗回归与生产构建也应通过。
