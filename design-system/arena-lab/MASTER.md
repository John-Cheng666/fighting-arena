# Arena Lab 设计系统

本次重构使用 ui-ux-pro-max，查询 `simulation control dashboard minimal`，已核对的风格为 **Minimalism & Swiss Style**。这是一个格斗观察与实验工具，布局采用工作台结构；生成结果中的营销首页结构不适用于本应用。

## 信息结构

- 主导航：自动对战、招式演练、对局记录。对战与演练可通过 `#battle`、`#training` 访问，支持浏览器前进和后退。
- 自动对战：配置双方 → 在竞技场上方开始 / 暂停 → 查看整局记录。
- 招式演练：选择招式与命中 / 防御 / 落空情境 → 明确点击开始 → 查看结果。选择变体会准备场景，不会自动播放。
- 选手参数与对局规则分开；每个席位独立配置。应用设置会明确提示重开与日志清空。
- 日志独立占据整行。筛选、搜索、伤害汇总与导出围绕同一份完整记录；翻页固定列表，继续记录新事件。

## 视觉与主题

`src/app/theme.css` 是实际颜色令牌来源。默认浅色，可切换并记住深色主题；竞技场保留深色舞台。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 | `#f4f5f7` | `#11151c` |
| 表面 | `#ffffff` | `#1a202a` |
| 正文 | `#1e2733` | `#edf1f6` |
| 次要文字 | `#596574` | `#b4bfce` |
| 主操作 | `#b84125` | `#f5a080` |
| 主操作文字 | `#ffffff` | `#2b1b15` |
| 1P 文字 | `#8d5b10` | `#e8bd72` |
| 2P 文字 | `#156c74` | `#87d1da` |

采用系统中文无衬线字体，数字与时间用等宽字体，避免远程字体依赖。常规内容 14–16px，辅助标签 12–13px；小于 12px 只用于英文装饰、编号和单位。文字对比度至少 4.5:1；必要控件边界至少 3:1。身份、选中和胜负同时使用文字与颜色。

4/8px 间距节奏；布局间距 16/24/32px；表面圆角 14px，输入与按钮圆角 7px。图标沿用统一的 SVG 描边系统。按钮不改变布局尺寸，动效仅用于状态反馈。

## 响应式与无障碍

- 桌面：竞技场与配置双栏，完整日志在下方。
- 800px 以下：单栏，演练选择器先于竞技场，双方状态在后。
- 600px 以下：双方卡片纵向排列，舞台两列，日志筛选和搜索换行。
- 原有方形战斗视角完整保留，宽屏用深色留边，支持全屏。
- 有跳过导航链接、可见焦点、带名称的图标按钮、表单标签、范围提示和状态语义。
- 配置标签页支持左右方向键及 Home / End；输入错误在字段旁提示，多项错误聚合并移动焦点。
- 主要操作目标至少 44px 高；尊重系统减少动态效果设置；固定导航为锚点和焦点留出空间。
- 主题与舞台保存在本机；战斗参数和日志属于当前页面会话。

## 代码组织

- `App.tsx`：主布局、导航、播放与主题。
- `FighterCard.tsx`、`CharacterSettings.tsx`：选手状态和参数。
- `MatchSettings.tsx`：规则、种子与表单反馈。
- `BattleLogPanel.tsx`：整局事件、筛选、分页、导出。
- `theme.css` / `layout.css` / `components.css` / `responsive.css`：主题、布局、组件和断点。
- `characters/jamie/ui/styles.css`：角色资源与演练组件，复用语义令牌。
